# 发给同事时怎么用

推荐直接发送：

```text
UE_M转UnityURP_Metallic工具_发给同事.zip
```

同事解压后，双击：

```text
UE_M_to_Unity_URP_Metallic_Tool.exe
```

这个 exe 已经内置运行环境和 Pillow，不需要同事安装 Python，也不需要手动安装 Pillow。

## 如果 exe 被安全软件拦截

可以使用备用源码版：

```text
源码版_备用_需要Python/启动工具.bat
```

这个启动脚本会在打开工具前自动检查：

- 是否有 Python
- 是否有 pip
- 是否有 Pillow

如果缺少 Pillow，会自动运行：

```text
python -m pip install --user --upgrade pillow
```

如果电脑没有 Python，脚本会提示先安装 Python，并提醒勾选 `Add Python to PATH`。

## 不要只发送 .pyw 文件

只发送 `.pyw` 时，同事电脑如果没有 Pillow，就会弹出缺少 `PIL` 的错误。建议发送完整 zip 包。
