# UE M 贴图转 Unity URP Metallic Alpha 工具

## 用途

把 UE 引擎常见的 M/Mask 混合贴图批量转换成 Unity URP Lit Metallic Workflow 可用的 Metallic Map。

Unity URP Lit 常用规则：

- R 通道 = Metallic
- A 通道 = Smoothness

UE 中常见的是 Roughness，Unity 需要的是 Smoothness，所以默认会执行：

```text
Smoothness = 1 - Roughness
```

## 支持格式

- 输入：PNG、TGA
- 输出：PNG、TGA
- 输出图为 RGBA，带 Alpha。

## 推荐设置

### UE ORM 常用贴图

很多 UE 资产使用：

```text
R = AO
G = Roughness
B = Metallic
```

工具中选择预设：

```text
UE ORM 常用：R=AO, G=Roughness, B=Metallic
```

输出结果：

```text
R = Metallic
A = Smoothness = 1 - Roughness
```

### 其他通道

如果你的 UE M 图不是 ORM，可以在工具里手动切换：

- Metallic 来源：R/G/B/A/0/1
- Roughness 来源：R/G/B/A/0/1
- AO 来源：只有在选择“自定义保留：R=Metallic, G=AO, B=0”时会写入 G 通道

## 输出 RGB 方式

推荐默认：

```text
RGB=Metallic 预览友好
```

Unity URP Lit 主要读取 R 和 A。RGB 都填 Metallic 方便你在资源管理器里预览黑白金属度。

如果你想更严格：

```text
严格URP：R=Metallic, G/B=0
```

## Unity 导入注意

导入 Unity 后：

- Texture Type：Default
- sRGB：关闭
- Alpha Source：Input Texture Alpha
- 在 URP Lit 材质中把贴图放到 Metallic Map
- Smoothness Source 使用 Metallic Alpha

## 文件命名

默认输出后缀：

```text
_UnityMetallic
```

如果输入文件是：

```text
T_Rock_01_M.png
```

默认会输出：

```text
T_Rock_01_UnityMetallic.png
```

## 输入目录和输出目录相同

工具支持输入目录与输出目录相同。

同目录转换时建议保持勾选：

```text
跳过已经带输出后缀的贴图
```

这样工具会处理原始 PNG/TGA，并跳过已经生成过的 `_UnityMetallic` 结果图，避免重复转换。
