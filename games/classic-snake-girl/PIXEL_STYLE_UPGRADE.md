# 像素风 UI 升级说明

## 改造范围

- 页面范围：`index.html`、`home.html`、`game.html`
- 资源范围：仅调整页面内联 CSS 视觉表现，未新增脚本依赖，未修改图片、音频和 Matter.js 逻辑

## 核心约束

- 保留所有原有功能逻辑、事件绑定、输入输出规则和页面跳转逻辑
- 保留所有现有 UI 元素的定位方式、布局结构、宽高参数和响应式断点
- 所有改造均限制在样式层，重点通过纹理、阴影、描边、高光和色彩层次增强像素风表现

## 视觉实现方式

- 为三个页面统一补充像素风设计变量，包括像素化表面纹理、阶梯式阴影和高光配色
- 为面板类组件添加复古像素表面纹理、角标高光和多层硬阴影，提升 8bit 视觉辨识度
- 为按钮、标签、抽屉、Dock、弹窗、进度条等交互元素增加像素化背景层和硬边阴影
- 对 `canvas` 预览区域补充 `image-rendering: pixelated`，强化像素化显示风格
- 对文字增加低强度阶梯阴影，在不改动字号和布局的前提下提升复古视觉质感

## 页面说明

### index.html

- 保留原有自动跳转逻辑和兜底链接
- 升级为像素风入口页，增加扫描线、像素栅格和像素面板边框

### home.html

- 保留主页所有模块切换、返回主页、开始游戏、本地状态保存逻辑
- 不调整现有模块顺序、网格结构、间距、宽高和断点
- 仅增强面板、卡片、按钮、摘要状态、奖励/任务/商店项的像素风视觉

### game.html

- 保留游戏画布、投放逻辑、排行榜、下一个核心、倒计时、设置抽屉、图鉴抽屉、底部 Dock、结算弹窗等全部功能
- 不调整 HUD、抽屉、底部 Dock、进度条和弹窗的位置参数
- 仅对各类面板和交互控件增加像素化描边、纹理和阴影表现

## 验证说明

- 已对 `index.html`、`home.html`、`game.html` 进行静态结构检查与诊断检查
- 已确认本次改造未改动 JavaScript 交互逻辑，仅修改视觉样式
- 已复查页面中的响应式断点规则，未改动原断点对应的布局尺寸和定位参数

## 建议的最终人工验收

- 桌面端：检查主页卡片、游戏 HUD、抽屉与结算弹窗视觉是否统一
- 平板端：检查抽屉、顶部状态区、底部 Dock 是否保持原布局关系
- 移动端：检查功能卡片单列堆叠、进度区和提示条是否保持可读性
- 交互链路：检查主页跳转、开始游戏、奖励领取、任务领取、商店选择、设置按钮、图鉴筛选、结算按钮是否全部正常
